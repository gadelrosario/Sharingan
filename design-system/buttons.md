# Buttons

## Primary Button

Use for the main action on a screen.

- Gold or purple fill
- High-contrast text
- Minimum height: `44px`
- Border radius: `12px`
- Font weight: `700`

## Secondary Button

Use for alternate actions.

- Elevated dark surface
- Visible border
- Primary text color

## Ghost Button

Use for low-priority controls.

- Transparent background
- Muted or secondary text
- Hover state required

## Danger Button

Use only for destructive actions.

- Danger color
- Clear action label
- Confirmation required when data loss is possible

## Disabled State

- Reduced opacity
- No hover animation
- Disabled cursor
- Must remain readable

## Button Language

Prefer direct labels:

- Start Draft
- Make Pick
- Undo Pick
- View Evidence
- Wait
- Compare Paths

Avoid vague labels:

- Continue
- Okay
- Submit
- Click Here
