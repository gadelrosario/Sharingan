# Typography

## Font Family

Use the application's existing system font stack unless a future brand font is
approved.

Recommended stack:

`Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`

## Type Scale

### Display

- Size: `32px`
- Weight: `800`
- Line height: `1.1`

### Page Heading

- Size: `24px`
- Weight: `750`
- Line height: `1.2`

### Section Heading

- Size: `18px`
- Weight: `700`
- Line height: `1.3`

### Card Title

- Size: `16px`
- Weight: `700`
- Line height: `1.3`

### Body

- Size: `14px`
- Weight: `400`
- Line height: `1.5`

### Metadata

- Size: `12px`
- Weight: `500`
- Line height: `1.4`

### Button

- Size: `14px`
- Weight: `700`

### Confidence Score

- Size: `18px`
- Weight: `800`

## Rules

- Avoid all-uppercase paragraphs.
- Uppercase may be used for compact labels and badges.
- Recommendation text should be concise and visually prominent.
- Supporting evidence should appear smaller and less prominent.
- Do not use more than three font weights within one component.
