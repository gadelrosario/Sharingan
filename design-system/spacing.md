# Spacing

Fantasy HQ uses a fixed spacing scale.

- `4px` — Micro spacing
- `8px` — Tight spacing
- `12px` — Compact component spacing
- `16px` — Standard spacing
- `24px` — Section spacing
- `32px` — Large separation
- `48px` — Major layout separation

## Rules

- Default card padding: `16px`
- Premium card padding: `20px` or `24px`
- Standard gap between stacked controls: `12px`
- Standard gap between cards: `16px`
- Standard section spacing: `24px`
- Avoid arbitrary values unless required for alignment.
- Do not reduce touch targets below `44px` in height.
