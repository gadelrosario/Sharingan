# Fantasy HQ Design System

## Purpose

The Fantasy HQ Design System defines the visual language, interaction patterns,
and writing standards used throughout the application.

Every new screen, panel, card, recommendation, badge, and animation should
follow these standards.

## Product Goals

- Fast readability during a live draft
- Premium appearance
- Minimal cognitive load
- Clear recommendation hierarchy
- Strong mobile usability
- Consistent behavior across NFL and NBA modes
- Distinct identities for major Fantasy HQ systems

## Core Principles

1. Important information should be understandable within five seconds.
2. Recommendations should be visually stronger than supporting evidence.
3. Waiting or taking no action must appear as a deliberate recommendation.
4. Purple and gold are brand colors, not decoration for every element.
5. Color should reinforce meaning, not replace text.
6. Components should remain readable on small screens.
7. New features should reuse existing components before introducing new styles.
