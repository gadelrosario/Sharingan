# Panels

Panels organize related information or system-level tools.

## Standard Panel

- Clear title
- Optional status indicator
- Consistent internal spacing
- Collapsible only when content is secondary

## Flight Control Panel

Should answer:

- Is there enough information?
- Should the user act now or wait?
- What flexibility is being preserved or lost?

## Sharingan Vision Panel

Should reveal deeper context without overwhelming the primary recommendation.

May include:

- Hidden risk
- Tier cliff
- Opponent behavior
- Alternate timeline
- Roster construction impact

## Command Center Panel

Should prioritize:

- Current state
- Recommended action
- Urgency
- Confidence
- Next decision point

## Mobile Rules

- Panels stack vertically.
- Primary recommendation appears before supporting evidence.
- Avoid horizontal scrolling.
